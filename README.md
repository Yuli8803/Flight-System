# Flight-System Application
This Flight System Application is a full-stack project developed as a final assignment for a database course. It features user authentication and comprehensive flight search and booking capabilities, backed by a robust PostgreSQL database.


# Key Features
* User Authentication: New users can sign up for an account, while returning users can log in securely.

* Flight Search & Filtering: Filter available flights by price or duration to find the best option.

* Booking System: Select travel dates and book flights directly through the application.

* PostgreSQL Integration: All application data—including user credentials, flight details, and booking records—is stored and managed across structured SQL tables.
